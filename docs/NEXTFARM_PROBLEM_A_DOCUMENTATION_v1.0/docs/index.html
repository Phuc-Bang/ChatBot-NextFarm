4. Source Governance

TIER 1

Authoritative

Cơ quan nhà nước, viện nghiên cứu, trường đại học, khuyến nông, tài liệu kỹ thuật chính thức.

TIER 2

Professional

Tổ chức chuyên ngành, doanh nghiệp nông nghiệp và tài liệu kỹ thuật có nguồn rõ.

TIER 3

Low-trust

Blog, forum, nội dung SEO, nguồn không rõ tác giả. Không mặc định là ground truth.

Tier chỉ là một phần. Cần xem authority + freshness + region + crop relevance + content quality + human verification.

Query Processing

Xử lý tiếng Việt có dấu/không dấu, viết tắt, lỗi chính tả và thuật ngữ nông nghiệp ở mức phù hợp.

Hybrid Retrieval

Vector search phù hợp semantic similarity; keyword search hữu ích với tên bệnh, thuật ngữ, số liệu và cụm từ chính xác.

Project Agreement

Chúng ta xây một chatbot tư vấn nông nghiệp tiếng Việt cho 3 cây lúa, cà chua và dưa chuột, sử dụng knowledge base có provenance và human verification, RAG với hybrid retrieval, evidence grounding, citation, abstention và evaluation; fine-tuning bằng open-source LLM + LoRA/QLoRA là lớp cải thiện behavior, không thay thế knowledge grounding.
